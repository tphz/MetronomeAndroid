# 🏃‍♂️ 超慢跑节拍器 (Super Jogging Metronome)

一款专为"超慢跑"爱好者设计的 Android 端高精度节拍器。支持 **120 / 150 / 180 BPM** 步频实时切换，内置运动记录与日历统计。界面简洁现代，支持后台稳定播放，采用硬件音频流采样级对齐算法，彻底解决普通软件的"定时器漂移"痛点。

---

## ✨ 核心亮点

1. **绝对精准，零漂移 (Sample-accurate)**
   - 180 BPM 要求每分钟响 180 下，即每秒 3 下。
   - 普通的编程定时器存在毫秒级系统抖动，长时间运行累积误差大，会导致节拍变慢。
   - 本项目通过 `AudioTrack` 音频回调机制，在声卡消费数据的底层线程中通过**采样点计数**（44.1kHz 采样率下，每 14700 个采样点精确触发一个节拍）实现节拍时间线完全锁定于硬件晶振，**连续运行 10 小时也绝对 0 漂移**。

2. **纯数学音频合成，零外部依赖**
   - 彻底摆脱 `.mp3`、`.wav` 等外部音频文件缺失导致软件报错崩溃的问题。所有声音波形均使用数学公式实时计算并预合成在内存中。
   - **双音色木鱼交替**：奇数拍播放 850 Hz 重音木鱼声（引导左脚），偶数拍播放 680 Hz 轻音木鱼声（引导右脚）。声音温润柔和，久听不累。
   - **舒缓结束提示音**：倒计时结束时，合成一段极柔和的 C 大三和弦（C5-E5-G5）琶音羽化淡出，而不是刺耳的闹铃声。

3. **卓越的后台运行能力**
   - 基于 **Foreground Service** 实现后台保活，支持锁屏控制。
   - 与音乐、有声书等应用同时播放，不抢占音频通道。
   - 支持与 **网易云音乐、QQ音乐、Spotify、有声书软件、浏览器视频** 等同时播放，完全不抢占通道。
   - Wake Lock 管理确保音频连续性。

4. **LED 视觉节拍指示**
   - 界面上配有与节拍同步的 **LED 脉动指示灯**。
   - 随着节拍，指示灯会呈"绿（重音左脚）- 蓝（轻音右脚）"高低交替微闪，运动视觉节奏感拉满。

5. **多种计时模式**
   - `30分钟倒计时` / `45分钟倒计时` / `自由跑步` / `自定义时长`（5~120分钟）
   - **步频三段式预设**：`轻松120` / `标准150` / `高效180`，跑步中可实时切换，无需停下调整。

6. **内置运动记录与日历统计**
   - 每次运动自动记录**起止时刻、时长、模式、完成状态**，少于 3 分钟的短运动自动忽略。
   - **日历窗口**：按月查看运动概况（跑步天数 / 总时长 / 连续天数）。
   - **周统计卡片**：按 ISO 周聚合，显示跑步天数、总时长、运动次数、日均时长。
   - **会话级钻取**：点击任意日期，逐条列出每次运动的时间范围、时长、模式和完成状态。

## 🛠 技术架构

| 层次 | 技术方案 |
|------|----------|
| UI | Jetpack Compose + Material 3 暗黑主题 |
| 状态管理 | StateFlow + ViewModel |
| 音频引擎 | AudioTrack (PERFORMANCE_MODE_LOW_LATENCY) + Oboe (低延迟) |
| 数据持久化 | Room 数据库 |
| 后台服务 | Foreground Service + MediaSession |
| 语言 | Kotlin 1.9.24 |
| 最低版本 | Android 8.0 (API 26) |

---

## 📂 项目结构

```
app/src/main/java/com/tangpenghui/metronome/
├── audio/           # PCM 音频合成与节拍调度
├── controller/      # 状态机与业务控制器
├── data/            # Room 数据库与数据访问
├── engine/          # 高精度定时器引擎
├── service/         # Foreground Service 与 MediaSession
└── ui/              # Compose 界面 (home/calendar)
```
